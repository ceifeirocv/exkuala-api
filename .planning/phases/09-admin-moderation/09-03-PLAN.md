<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client (admin JWT) → AdminEventsController | Role claim must be enforced before any moderation handler runs |
| admin path → event ownership | Admin actions intentionally bypass ownership — bypass must be reachable ONLY by admins |
| service → event_audit_log | Every action must record the acting admin (non-repudiation) |
| public/organizer queries → soft-deleted/SUSPENDED events | Removed/suspended events must not leak to non-admin surfaces |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-03-01 | Elevation of Privilege | every /admin/events route | mitigate | `@Roles('admin')` on each route (D-16) + global RolesGuard → 403 for user/organizer tokens. Covered by controller spec + existing RolesGuard tests. |
| T-09-03-02 | Elevation of Privilege | ownership bypass in adminSuspend/Restore/Remove | mitigate | Bypass lives only in AdminEventsService, reachable solely through @Roles('admin') routes; organizer EventsController has no path to these methods (D-05). |
| T-09-03-03 | Repudiation | suspend/restore/remove audit rows | mitigate | adminUserId from @CurrentUser().id, persisted via create()+save() (Pitfall 3); immutable audit row. |
| T-09-03-04 | Information Disclosure | soft-deleted events | mitigate | withDeleted() only on the admin list path; public/organizer queries keep default @DeleteDateColumn filtering (09-RESEARCH security table). |
| T-09-03-05 | Information Disclosure | SUSPENDED event editing by organizer | mitigate | EventsService.update() 409 on SUSPENDED (D-01) — organizer cannot modify or self-restore. |
| T-09-03-06 | Tampering | adminUserId source | mitigate | Derived server-side from verified AuthenticatedUser.id, never from request body. |
</threat_model>
