  <what-built>
Phase 5 Organizers module:
- POST /api/v1/organizers — authenticated users submit organizer applications (status starts as pending)
- GET /api/v1/organizers/me — authenticated users view their own application + latest rejection note
- GET /api/v1/organizers/:id — public profile (approved organizers only, no email)
- PATCH /api/v1/admin/organizers/:id/approve — admin approves application
- PATCH /api/v1/admin/organizers/:id/reject — admin rejects application with optional note
- GET /api/v1/admin/organizers?status= — admin lists organizers by status
- GET /api/v1/admin/organizers/:id/history — admin views audit log for an organizer
- State machine enforcement: pending→approved|rejected, rejected→pending, approved is terminal
  </what-built>
  <how-to-verify>
Start the application:
```bash
cd /home/ceifeiro/Code/exkuala-api && pnpm start:dev
```

**Step 1 — Submit an application (requires valid JWT for a user role):**
```bash
curl -X POST http://localhost:3000/api/v1/organizers \
  -H "Authorization: Bearer {USER_JWT}" \
  -H "Content-Type: application/json" \
  -d '{"name":"Test Org","description":"A test organizer","email":"test@org.pt"}'
```
Expected: 201 with `{"status":"pending","name":"Test Org",...}`. Note the returned `id`.

**Step 2 — Get own profile:**
```bash
curl http://localhost:3000/api/v1/organizers/me \
  -H "Authorization: Bearer {USER_JWT}"
```
Expected: 200 with all fields including `email` and `latestRejectionNote: null`.

**Step 3 — Admin approve (requires valid JWT for admin role):**
```bash
curl -X PATCH http://localhost:3000/api/v1/admin/organizers/{ORGANIZER_ID}/approve \
  -H "Authorization: Bearer {ADMIN_JWT}" \
  -H "Content-Type: application/json" \
  -d '{"note":"Verified."}'
```
Expected: 204 No Content.

**Step 4 — Public profile (no JWT needed):**
```bash
curl http://localhost:3000/api/v1/organizers/{ORGANIZER_ID}
```
Expected: 200 with `name`, `description`, `website`, `socialLinks`. Confirm `email` is NOT in the response.

**Step 5 — Public profile for a pending organizer returns 404:**

  -H "Authorization: Bearer {ADMIN_JWT}" \
  -H "Content-Type: application/json" \
  -d '{}'

Expected: 409 with message containing "already approved".
