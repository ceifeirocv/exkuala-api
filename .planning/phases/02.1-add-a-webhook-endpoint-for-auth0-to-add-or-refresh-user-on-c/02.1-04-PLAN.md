**Create `src/webhooks/webhooks.controller.ts`** (per D-03, D-05, D-07):

```typescript
import { Body, Controller, HttpCode, Post, UseGuards } from '@nestjs/common';
import { Public } from '../auth/decorators/public.decorator';
import { UsersService } from '../users/users.service';
import { Auth0WebhookDto } from './dto/auth0-webhook.dto';
import { WebhookSecretGuard } from './guards/webhook-secret.guard';

// POST /api/v1/webhooks/auth0
// Receives Auth0 Action calls on post-login and post-register events.
// @Public() bypasses the global JwtAuthGuard — this route has no JWT.
// @UseGuards(WebhookSecretGuard) enforces the shared-secret header check instead.
@Controller('webhooks')
export class WebhookController {
  constructor(private readonly usersService: UsersService) {}

  @Public()
  @UseGuards(WebhookSecretGuard)
  @Post('auth0')
  @HttpCode(200)
  async handleAuth0Webhook(@Body() dto: Auth0WebhookDto): Promise<void> {
    await this.usersService.upsertFromAuth0(dto.sub);
  }
}
```

**Create `src/webhooks/webhooks.module.ts`** (per RESEARCH.md Pattern 6):

```typescript
import { Module } from '@nestjs/common';

// IMPORTANT: Do NOT register APP_GUARD providers here.
// JwtAuthGuard and RolesGuard are already APP_GUARD in AuthModule.
// Re-registering them would cause double-execution on all routes.
@Module({
  imports: [UsersModule],   // UsersModule exports UsersService (required for WebhookController injection)
  controllers: [WebhookController],
  providers: [WebhookSecretGuard],
})
export class WebhooksModule {}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Auth0 → POST /api/v1/webhooks/auth0 | Unauthenticated external HTTP caller — x-webhook-secret is the only trust anchor |
| Global JwtAuthGuard → @Public() route | JwtAuthGuard short-circuits on @Public() metadata — no JWT required on this path |
| WebhookSecretGuard → controller | Guard runs after both APP_GUARDs; controller only executes when guard returns true |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02.1-01 | Spoofing | POST /webhooks/auth0 — missing/wrong x-webhook-secret | mitigate | WebhookSecretGuard.canActivate() returns false on missing or wrong header. NestJS translates false → 401 UnauthorizedException. Auth0 Action receives 401 (not 200 or 500). |
| T-02.1-02 | Information Disclosure | WebhookSecretGuard.timingSafeEqual | mitigate | Length check before timingSafeEqual prevents TypeError becoming 500. Constant-time comparison prevents timing oracle. |
| T-02.1-03 | Spoofing | Replay attack — Auth0 resends webhook on 5xx | accept | upsertFromAuth0 uses ON CONFLICT DO UPDATE — idempotent at DB level. Replaying the same sub produces no new rows. No nonce/timestamp check needed for a pure upsert operation. |
| T-02.1-04 | Denial of Service | AppModule — WEBHOOK_SECRET missing at startup | mitigate | env.validation.ts (Plan 02) declares WEBHOOK_SECRET @IsString() required. ConfigModule validate() runs before any request. Missing secret crashes process with descriptive error before HTTP server starts. |
| T-02.1-05 | Tampering | UsersService / TypeORM parameterized SQL | accept | repository.upsert() generates parameterized INSERT ... ON CONFLICT. No raw SQL. TypeORM pg driver uses parameter binding throughout. auth0Id column is varchar(128) — DB enforces max length. |
</threat_model>
