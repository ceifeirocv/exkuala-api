  <action>
Run the TypeORM migration to create the categories schema in the database.

The migration command builds first (compiles TypeScript to dist/), then runs TypeORM CLI against the compiled data-source:

```bash
pnpm migration:run
```

This command is defined in package.json as:
`pnpm run build && npx typeorm migration:run -d dist/database/data-source.js`

Expected output includes a line confirming the `Categories1746000000000` migration ran:
```
query: INSERT INTO "migrations"("timestamp","name") VALUES ($1, $2) -- PARAMETERS: [1746000000000,"Categories1746000000000"]
Migration Categories1746000000000 has been executed successfully.
```

If the migration fails with a "relation already exists" error, it means a previous partial run left the table. Run `pnpm migration:revert` first, then re-run `pnpm migration:run`.

If the migration fails with a database connection error, verify that `DATABASE_URL` is set in `.env` and the PostgreSQL server is running.

NOTE: There may be npm/pnpm SSL config warnings in the output (documented in STATE.md Pending Todos). These warnings are cosmetic — ignore them if the migration success message appears.
  </action>
